## agent_workflows/13_error_recovery.py

```
=== Scoped recovery: fall back to cached data ===
  fetch: retry_number=0 last_exception=None
  fetch: retry_number=1 last_exception=ConnectionError('upstream API is down')
  recovery: fetch failed after 2 attempts with ConnectionError: upstream API is down
Result: yesterday's prices (from cache)

=== Catch-all recovery with a spent budget ===
  unstable: call 1
  recovery: retrying after TimeoutError
  unstable: call 2
  recovery: retrying after TimeoutError
  unstable: call 3
  Workflow failed once max_recoveries was exhausted: provider timed out
```

> First block: retries are exhausted, then `@catch_error(for_steps=["fetch"])` turns
> the failure into a cache hit. Second block: the wildcard handler loops back into
> the failing step, so `max_recoveries=2` allows exactly two rescues and the third
> failure propagates.
